# SILLA TICKET

Application Android pour vendre et gérer des tickets Wi-Fi sur routeurs MikroTik
(User Manager et Mikhmon), par AI FRATERNITÉ.

## Télécharger

➡️ **[Dernière version : SILLA-TICKET.apk](https://github.com/Abdel4564/silla-ticket/releases/latest/download/SILLA-TICKET.apk)**

Toutes les versions : [Releases](https://github.com/Abdel4564/silla-ticket/releases)

## Installer

1. Ouvre le lien ci-dessus sur le téléphone Android et télécharge le fichier.
2. Si Android le demande, autorise « Installer des applications inconnues » pour ton navigateur.
3. Ouvre le fichier téléchargé et touche « Installer ».

Les mises à jour suivantes se font directement dans l'application.
